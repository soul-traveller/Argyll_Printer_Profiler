# Argyll_Printer_Profiler.command — User Guide
**Version:** 1.3.2<br>
**Platform:** macOS, Linux and Windows<br>
**Loosly Based on:** Simple script by Jintak Han (https://github.com/jintakhan/AutomatedArgyllPrinter)<br>
**Author:** Knut Larsson<br>

Argyll_Printer_Profiler.command is an advanced interactive terminal script that automates a complete **ArgyllCMS printer profiling workflow** on macOS, Linux and Windows, from target generation to ICC profile installation.<br>
